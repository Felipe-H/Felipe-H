## Currently Building

| | |
|---|---|
| **Corporate intranet** | Five repositories, three APIs and one shared schema. New modules grow around a legacy database that stays online — no big-bang migration, no downtime window. Real-time chat and presence, five-level permissions, payroll import that reads the PDF instead of trusting the filename. |
| **Event platforms** | Three generations of the same product line: from landing page with referral scoring, to digital gate and attendance, to an admin panel with editable e-mail templates and a full audit trail. |
| **3D portfolio hub** | React Three Fiber. Each project is a portal; opening one renders a paginated case dossier. Content lives in a validated JSON contract, never in the components. |

> Most of this work lives in private repositories. What is public here are older
> and side projects — the contribution graph reflects the daily work.
